## 🏗️ Про проект

Мета роботи — продемонструвати розуміння та практичне застосування патерну **Mediator**. 

### Опис патерну
**Посередник** — це поведінковий патерн проектування, який дає змогу зменшити зв’язність великої кількості класів між собою, завдяки переміщенню цих зв’язків у один клас-посередник.

### Структура файлів
* `src/behavioral/Mediator/Mediator.ts` — основний інтерфейс посередника та базовий клас компонентів.
* `src/main.ts` — точка входу для демонстрації роботи коду.
* `package.json` — конфігурація проекту та залежностей.
